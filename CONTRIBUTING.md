# Contributing

This public repository accepts product feedback. It does not accept patches against the implementation, because the implementation is not published here.

## Useful reports

- A prompt that returned a wrong or unsafe answer, with the date and the app version.
- A fee that did not match the published $0.002 price.
- A privacy problem: personal content appearing as shared knowledge, or a prompt appearing in a public record.
- A client bug: install, sign-in, or a conversation that fails on a current store build.

Include what you expected and what happened. Leave out recovery phrases, private keys, and the text of personal prompts.

## What we will not do in this repository

- Review design proposals for how the network chooses blocks.
- Publish internal interfaces so a reader can reimplement the client or the chain.
- Coordinate launch-day voting or promotion.

Security reports that describe a user-visible failure can be sent through the contact published with the repository. Reports that ask for unpublished internals will not be answered with those internals.
